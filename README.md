# T Level Engineering Core — study app

Revision app for the T Level in Engineering and Manufacturing — Core (Units 1–17).

- **Web app:** `index.html` — open it from GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/root`).
- **Privacy policy:** `privacy-policy.html` (link this in Google Play Console).
- **Android app:** the `android/` folder is the Android Studio project. See `android/README.md` for build and Google Play steps; store graphics and listing text are in `android/store/`.

Each unit has key learning, flip-card key terms, interactive activities and a 20-question test bank (340 questions in total), plus full mixed mock exams. No sign-in: each student's name and results are saved only on their own device.

Original revision material written to follow the T Level Engineering and Manufacturing Core specification.
